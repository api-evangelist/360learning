360Learning is a collaborative learning platform (LMS) that blends top-down and peer-to-peer "Collaborative Learning" to help enterprises upskill and train employees, customers, and partners at scale. Its REST API v2 lets developers automate the platform: provision and activate users, organize them into groups, build and assign courses and learning paths, schedule instructor-led classrooms with slots and attendance, manage a skills taxonomy and certificates, run bulk operations, and subscribe to near-real-time webhook events. API v2 uses OAuth 2.0 client-credentials auth with a two-tier (company/credential) scope system, cursor pagination via the Link header, and is hosted in EU and US regions.

**Areas:** Company · EdTech · LMS · E-Learning · Training · Collaborative Learning · Human Resources · Skills

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).
