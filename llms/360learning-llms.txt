## API Reference
- [List all certificate outlines](https://360learning.readme.io/reference/v2certificateoutlinesgetcertificateoutlinescontroller_getcertificateoutlines.md): > 🔑 > > Required OAuth scope: `certificateOutlines:read`.  Lists all certificate outlines in your platform.
- [Create certificate outline](https://360learning.readme.io/reference/v2certificateoutlinescreatecertificateoutlinecontroller_createcertificateoutline.md): > 🔑 > > Required OAuth scope: `certificateOutlines:write`.  Creates a new certificate outline in your platform.
- [Delete a certificate outline](https://360learning.readme.io/reference/v2certificateoutlinesdeletecertificateoutlinecontroller_deletecertificateoutline.md): > 🔑 > > Required OAuth scope: `certificateOutlines:write`.  Deletes a specific certificate outline given its unique ID.
- [Edit a certificate outline](https://360learning.readme.io/reference/v2certificateoutlinesupdatecertificateoutlinecontroller_updatecertificateoutline.md): > 🔑 > > Required OAuth scope: `certificateOutlines:write`.  Edits specific fields of an existing certificate outline. Fields not included in the request payload remain unchanged.
- [Create a classroom](https://360learning.readme.io/reference/v2classroomscreateclassroomcontroller_createclassroom.md): > 🔑 > > Required OAuth scope: `classrooms:write`.  Creates a classroom.
- [List all classrooms](https://360learning.readme.io/reference/v2classroomsgetclassroomscontroller_getclassrooms.md): > 🔑 > > Required OAuth scope: `classrooms:read`.  > 📖 > > This endpoint is paginated with a page size of 500 classrooms. For more information, see the [Pagination guide](doc:pagination).  Lists all classrooms in your platform.
- [Retrieve a classroom](https://360learning.readme.io/reference/v2classroomsgetclassroomcontroller_getclassroom.md): > 🔑 > > Required OAuth scope: `classrooms:read`.  Retrieves information about a classroom given its ID.
- [Edit a classroom](https://360learning.readme.io/reference/v2classroomsupdateclassroomcontroller_updateclassroom.md): > 🔑 > > Required OAuth scope: `classrooms:write`.  Edits specific fields of an existing classroom. Fields not included in the request payload remain unchanged.
- [Add a slot to a classroom](https://360learning.readme.io/reference/v2classroomscreateclassroomslotcontroller_createclassroomslot.md): > 🔑 > > Required OAuth scope: `classrooms:write`.  Adds a slot to a given classroom.
- [List all slots in a classroom](https://360learning.readme.io/reference/v2classroomsgetclassroomslotscontroller_getclassroomslots.md): > 🔑 > > Required OAuth scope: `classrooms:read`.  > 📖 > > This endpoint is paginated with a page size of 100 classroom slots. For more information, see the [Pagination guide](doc:pagination).  Lists all slots in a given classroom.
- [Remove a slot from a classroom](https://360learning.readme.io/reference/v2classroomsdeleteclassroomslotcontroller_deleteclassroomslot.md): > 🔑 > > Required OAuth scope: `classrooms:write`.  Removes a slot from a classroom based on the provided slot ID.
- [Create an attendance sheet](https://360learning.readme.io/reference/v2classroomscreateattendancesheetcontroller_createattendancesheet.md): > 🔑 > > Required OAuth scope: `attendanceSheets:write`.  Creates an attendance sheet for the given classroom slot.
- [Edit a classroom slot](https://360learning.readme.io/reference/v2classroomsupdateclassroomslotcontroller_updateclassroomslot.md): > 🔑 > > Required OAuth scope: `classrooms:write`.  Edits specific fields of an existing classroom slot. Fields not included in the request payload remain unchanged.
- [List all attendance sheets](https://360learning.readme.io/reference/v2classroomsgetattendancesheetscontroller_getattendancesheets.md): > 🔑 > > Required OAuth scope: `attendanceSheets:read`.  > 📖 > > This endpoint is paginated with a page size of 3,000 attendance sheets. For more information, see the [Pagination guide](doc:pagination).  Lists all attendance sheets in your platform for the given classroom slot.
- [Delete an attendance sheet](https://360learning.readme.io/reference/v2classroomsdeleteattendancesheetcontroller_deleteattendancesheet.md): > 🔑 > > Required OAuth scope: `attendanceSheets:write`.  Deletes a specific attendance sheet given its unique ID.
- [Replace an attendance sheet](https://360learning.readme.io/reference/v2classroomsupdateattendancesheetcontroller_updateattendancesheet.md): > 🔑 > > Required OAuth scope: `attendanceSheets:write`.  Replaces the attendance sheet in the given classroom slot.
- [List all attendances](https://360learning.readme.io/reference/v2classroomsgetattendancescontroller_getattendances.md): > 🔑 > > Required OAuth scope: `attendanceSheets:read`.  > 📖 > > This endpoint is paginated with a page size of 3,000 attendances. For more information, see the [Pagination guide](doc:pagination).  Lists all attendances in your platform for the given classroom slot and attendance sheet.
- [Register a user to a classroom slot](https://360learning.readme.io/reference/v2classroomsaddslotregistrationcontroller_addslotregistration.md): > 🔑 > > Required OAuth scope: `classrooms:write`.  Registers a user to a classroom slot based on the provided classroom slot ID and user ID.
- [List all registrations in a classroom slot](https://360learning.readme.io/reference/v2classroomsgetslotregistrationscontroller_getslotregistrations.md): > 🔑 > > Required OAuth scope: `classrooms:read`.  > 📖 > > This endpoint is paginated with a page size of 2,000 slot registrations. For more information, see the [Pagination guide](doc:pagination).  Lists all users registered to a given classroom slot.
- [Edit a classroom slot registration](https://360learning.readme.io/reference/v2classroomsupdateslotregistrationcontroller_updateslotregistration.md): > 🔑 > > Required OAuth scope: `classrooms:write`.  Edits specific fields of an existing classroom slot registration. Fields not included in the request payload remain unchanged.
- [List all registrations in a classroom](https://360learning.readme.io/reference/v2classroomsgetclassroomregistrationscontroller_getclassroomregistrations.md): > 🔑 > > Required OAuth scope: `classrooms:read`.  > 📖 > > This endpoint is paginated with a page size of 2,000 slot registrations. For more information, see the [Pagination guide](doc:pagination).  Lists all users registered to any slot in the given classroom.
- [List all waitlist requests in a classroom slot](https://360learning.readme.io/reference/v2classroomsgetclassroomslotwaitlistcontroller_getclassroomslotwaitlist.md): > 🔑 > > Required OAuth scope: `classrooms:read`.  Lists all waitlist requests in a given classroom slot.

For more information, see the [Pagination guide](doc:pagination).  Lists all courses statistics in your platform.
- [Archive or restore a course](https://360learning.readme.io/reference/v2coursesarchiveorunarchivecoursecontroller_archiveorunarchivecourse.md): > 🔑 > > Required OAuth scope: `courses:write`.  Archives or restores a course. Archiving a course doesn't remove it from paths where it is included. It simply prevents the course from being added to new paths. The archived course will still be accessible in existing paths, but it will be hidden from search results. Statistics are kept and not deleted.
